# Evidence Folder

Use this folder only for approved evidence.

## Approved Evidence Examples

- Sanitized screenshots
- Import job ID
- Import job status output
- Failed record summary
- Reconciliation summary
- Sign-off notes

## Do Not Store Here

- Real Management API tokens
- Real client secrets
- Production user exports
- Raw files containing sensitive PII
- Client data without approval
